# Software Disruption — Website

Corporate website for **Software Disruption**, a software engineering and digital-transformation partner in the GCC (UAE & Saudi Arabia).

## Tech Stack

The site is a **plain HTML/CSS/JS** static website with **one exception**: the **`/blog`** section is generated with **[Hugo](https://gohugo.io)**, a fast static-site generator.

| Layer               | Technology                                |
| ------------------- | ----------------------------------------- |
| Main site           | Static HTML, CSS, JavaScript              |
| Blog                | Hugo (content in Markdown)                |
| Output location     | Published directly into the repo root     |

## Project Structure

```
software-disruption-website/
├── index.html          # Homepage
├── about/ services/    # Static HTML pages
├── assets/             # Images, CSS, JS
├── site/
│   ├── content/blog/   # Blog posts (Markdown)
│   └── layouts/        # Hugo templates for the blog
├── blog/               # Generated by Hugo (do not edit by hand)
└── hugo.toml           # Hugo configuration
```

Hugo writes its output (the `blog/`, `blog/tags/` folders) directly into the repo root, so the rest of the site stays untouched and deploys as one plain static bundle.

## Getting Started

### 1. Install Hugo

Requires Hugo **0.141+** (extended edition). Install from [gohugo.io/installation](https://gohugo.io/installation/) or, on macOS:

```sh
brew install hugo
```

### 2. Build the Blog

```sh
hugo
```

This renders the blog Markdown into static HTML at the repo root.

### 3. Local Development

```sh
hugo server
```

Then open `http://localhost:1313/blog/` to preview. Changes to Markdown files reload instantly.

## How to Write a Blog Post

1. **Create a new Markdown file** in `site/content/blog/`, e.g. `site/content/blog/my-post.md`.
2. **Add front matter** at the top of the file — this is the metadata Hugo uses to render the post:

   ```yaml
   ---
   title: "My Post Title"
   description: "Short summary shown in search and social previews."
   date: 2026-09-20
   author: "Your Name"
   slug: "my-post"
   tags: ["Software Development", "AI", "GCC"]
   featured_image: "/assets/img/my-post-cover.jpg"
   thumb_class: "ph-blog-1"
   ---
   ```

3. **Write the content** below the front matter using Markdown (headings, lists, code blocks, images, and even raw HTML).
4. **Save and build** — Hugo picks the file up automatically:

   ```sh
   hugo
   ```

   The post will appear at `https://yourdomain/blog/my-post/` and on the `/blog/` listing page.

   > Tip: use `hugo server` while writing and preview at `http://localhost:1313/blog/`.

## What Is Hugo?

Hugo is an award-winning, open-source **static site generator** written in Go. It takes plain text files (Markdown) plus templates and renders them into a complete static website in milliseconds.

**Why it fits this project:**

- **Speed** — pages are pre-built HTML, so there is nothing to generate on each visit; it loads fast and needs no server-side processing.
- **Simple workflow** — anyone on the team writes a blog post as a plain Markdown file; no database or CMS to maintain.
- **Low maintenance** — output is plain HTML that can be hosted anywhere (static hosting, CDN, or a plain checkout of this repo).
- **SEO-friendly** — tag archives, clean URLs, and lightweight pages out of the box.

In short: **write Markdown, run `hugo`, ship HTML.**

## Deployment

Content is committed as a plain static checkout (HTML + generated blog folders). Push to the repository and the hosting/deploy pipeline serves the repo root as-is.
